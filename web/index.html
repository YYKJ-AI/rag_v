文档导入

上传 Markdown 文档，进入与 CLI 相同的确定性路线：front-matter 打标 → SimHash 指纹 → 父子分块 → 幂等入库；若模型/向量环境在线，随后自动向量化写入 pgvector（离线时明确标注跳过，导入不回滚）。

选择一份 .md 文档（需包含完整的 front-matter 元数据）

同内容重复导入会幂等跳过；同 ID 不同内容会明确报错要求升版本号。
格式要求（front-matter 示例）
---
id: my-notice    # 文档唯一标识
version: v1    # 版本号（同 ID 不同内容须升版本）
title: 文档标题
doc_type: 补充说明    # 基础规范/修订通知/补充说明/常见问答 等
effective_date: 2026-06-01    # 生效日期（必填）
replaces: other-notice@v1    # 可选：替代的旧版本
scope_keys: "*"    # 可选：适用范围键，逗号分隔
---
正文用 ## 节标题 分节，每节一段或数段事实内容。
