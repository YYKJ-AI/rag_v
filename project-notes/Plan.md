# ragbot 工作计划

## 工作规则

- 每项新工作先在本文件写目标、范围、验收条件和测试计划，再从非 `main` 的工作基线创建任务分支。
- 在任务分支完成实现与验证；实际改动记入 `issues.md`，测试结果记入 `test.md`，发现和修复的缺陷记入 `bug.md`。
- 任务完成、测试通过且记录齐全后，才能合回原非 `main` 分支。合入 `main` 必须由用户明确提出；未经该指令不得合入 `main`。
- 失败的测试必须先修复或明确记录为未完成；不能把未通过的任务标为完成。

## 后续研发计划：提高离线问答的通用性

依据 `可追溯知识库问答研发任务书-叶绍康.md`，按独立任务分支逐项推进；每项开工前补充该项的验收条件和测试案例。

1. **修正评测口径。**修复拒答案例汇总计数；区分有答案问题的检索命中率与拒答正确率；跨文档问题要求所有标注来源命中；记录文档版本和引用支持情况；更新可复现基线及 README。
2. **修正版本和适用范围。**按业务生效日与明确替代关系处理当前及历史查询；未来版本不得提前成为现行依据；按查询适用范围处理证据；补充边界测试。
3. **接通真实子块检索。**让索引使用导入生成的子块，再聚合到可定位的父块；用长文、流程和表格样本检查召回与噪声。
4. **扩充文档类型和证据判定。**加入项目方案、介绍、流程、表格等虚构资料；区分直接摘录、多来源合并、需要计算或推断的查询；证据不足时拒答，不以固定问句映射答案。
5. **完善交付验证。**补恶意文档指令、无效元数据、并发 HTTP、现行与历史版本、多类型新增文档等测试；划分开发与保留评测集；整理不超过两页的结果说明。

以上为计划，完成情况以对应任务分支的代码、测试与记录为准。

## 已完成任务：修正评测口径

**目标：**让逐条结果、汇总指标和引用来源检查采用同一套可解释的口径，形成可复现的离线基线。

**范围：**修改评测结构、统计、查询标注、CLI 报告和 README 基线说明；不修改问答与检索算法。后续版本裁决、子块检索和多类型文档按上方独立任务处理。

**原工作分支：**`work/ragbot`。

**任务分支：**`fix/evaluation-metrics`；完成后仅合回 `work/ragbot`。

**状态：**评测实现、标注、基线快照和说明已完成；14 条演示查询与相关测试通过。任务分支已合回 `work/ragbot`；`main` 未合并。

**验收条件：**

1. 汇总通过数等于逐条 `pass=true` 的数量；正确拒答计入通过数，拒答准确率有明确分子和分母。
2. Hit@5 仅统计有答案案例；一条案例要求的所有文档均进入前五才算命中。
3. 有出处率仅统计有答案案例；单列标注来源及版本的覆盖情况，并验证引用摘录能在对应检索父块原文中定位。该检查不宣称语义事实正确。
4. 耗时以小数毫秒记录，明确仅测回答调用，并在报告中列出指标分母。
5. 使用隔离数据目录导入 `docs/` 的八份资料并运行 14 条查询；README 与实际结果一致，保留失败项及局限。

**测试计划：**先用聚焦单测复现计数、分母、多来源、版本和引用定位问题，再修复；运行聚焦测试、`go test ./...`、`go vet ./...`，执行隔离目录 CLI 导入和评测，逐条核对报告与基线。

**范围：**修改版本筛选、冲突裁决、引用状态文字及检索候选顺序；为文档增加可选的机器可读 `scope_keys`，问答接口增加可选 `scope_key`。原有展示用 `scope` 保留；未指定范围的现有问答保持兼容。此项不扩展文档类型或重构子块检索。

**原工作分支：**`work/ragbot`。

**任务分支：**`fix/version-scope`；完成后仅合回 `work/ragbot`。

**状态：**日期与范围筛选、演示资料、接口和边界测试已完成；14 条演示查询通过。任务分支已合回 `work/ragbot`，`main` 未合并。

**验收条件：**

1. 未指定时间时按当前业务日期，显式或问句推断时间时按对应日期，过滤尚未生效及已被有效版本明确替代的证据；不同文档 ID 的显式替代也生效。

**目标：**检索索引真正使用导入生成的子块，并将命中聚合回可定位的父块；让长资料的局部内容、流程步骤和表格行能够被检索，而不会被整节无关内容稀释。

**范围：**修改内存检索索引和命中结构，保留现有父块引用接口；补充真实子块、多子块聚合、长文/流程/表格测试与说明。此项不重写回答生成或文档类型模型。

**原工作分支：**`work/ragbot`。

**任务分支：**`feature/real-chunk-retrieval`；完成后仅合回 `work/ragbot`。

**状态：**真实子块索引、父块聚合及长文/流程/表格测试完成；14 条演示查询通过。任务分支待合回 `work/ragbot`，`main` 不合并。

**验收条件：**

1. `Index` 使用传入的真实 `Chunk` 而非由父块临时生成伪子块；`Hit.Chunk` 能标明实际命中子块，`Hit.Section` 仍为可定位的父块。

3. 长文中远离开头的目标片段、流程末尾步骤和表格目标行可检索；无关子块不会仅因处于同一父块而虚假命中。
4. 原有演示问答和 14 条评测在全新数据目录复跑；如有失败，记录真实原因并修复或保留为未完成。

**测试计划：**先写检索聚焦测试验证真实子块 ID、局部召回、父块聚合及排序；跑全量 Go 测试、`go vet ./...` 和隔离目录 CLI 导入/评测，核对参考基线与 README。
