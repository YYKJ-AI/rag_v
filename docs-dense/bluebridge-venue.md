# 蓝桥手作营场地与安全执行细则

## 场地报备
组织者应在活动开始前七个自然日向蓝桥社区文化服务窗口提交场地报备表，填写教室、预计人数、设备清单和无障碍通道需求。窗口受理后给出报备编号；编号只证明材料已收，不代表安全许可已经核发。
若使用普通纸艺教室，组织者按报备编号预约桌椅即可。若使用木工教室并开启切割设备，除场地报备外还必须取得安全许可；安全许可由社区安全员审核设备防护、现场负责人和紧急停机方案。
预计人数超过四十人的场次，无论使用哪个教室，均须增加一名现场疏导员并提交分流路线图。人数恰好四十人的场次不触发该附加要求，但木工切割设备的安全许可要求仍然适用。

## 现场检查与例外
开场前负责人要核对灭火器有效期、应急通道和设备断电按钮。三项检查都须记录在现场检查表；完成场地报备不能代替现场检查，取得安全许可也不能免除这三项检查。
纸艺场次不使用切割设备时，不需要木工设备安全许可，但仍要做现场检查。临时更换教室时，负责人须更新报备表中的教室信息；如果新教室也启用切割设备，还应重新核对安全许可的适用教室。
发现应急通道被物料堵塞时，应先停止入场并清理通道，复核后才可开场。不能用“参加者已到齐”作为跳过检查的理由；现场负责人记录复核时间和处理人。

## 人员与物料
组织者每场安排一名主讲、一名材料管理员；预计人数超过四十人时，另安排现场疏导员。材料管理员负责发放工具和清点回收，不代替主讲完成设备安全示范。
切割工具只在木工教室由主讲发放。纸艺教室的剪刀和胶水由材料管理员发放，胶水按人数登记领用；这些物料登记与入场卡发放属于不同流程。
每场结束后材料管理员在三十分钟内核对工具数量并记录损坏情况。工具损坏记录只用于维护，不直接认定参加者应承担赔偿；是否收费以预算与退费说明中明确的项目为准。

## 对外告知
组织者在报名页公布场地位置、无障碍入口和活动时段。报名页可说明需要监护人签字，但不展示申请人的证件照片或联系方式。
遇到停电或暴雨导致场地不能使用时，窗口先发布暂停通知，再确认补办时间。暂停通知不是取消报名；新的场次是否需要重新申请，由窗口在后续通知中明确。
