# 中央广场场地使用补充通知

## 场地报备要求
在中央广场举办聚集性活动的，除按申请指南提交材料外，还须提前五个工作日向广场管理站报备活动规模与设备清单。超过五百人规模的活动须另行取得安全许可。

## 场地使用时段
中央广场开放使用时段为每日八时至二十一时。音响设备使用时段为九时至十二时及十四时至十八时。

## 保证金
使用中央广场舞台区域的，须缴纳场地保证金两千元，活动结束且场地验收合格后十个工作日内无息退还。
