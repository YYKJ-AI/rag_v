## 2026-11-11：修正评测口径

- **分支：**`fix/evaluation-metrics`，从 `work/ragbot` 创建；合并目标仅为 `work/ragbot`。
- **原因：**原报告把正确拒答漏计入总通过数，Hit@5 对多来源只需一个命中，且有出处率把拒答放入分母；整数毫秒使快速调用经常显示 0。
- **改动：**评测报告增加各指标分子、分母及逐条引用信息；有答案案例要求全部标注文档进入前五、全部标注的文档版本被引用、所有引用摘录在对应检索父块原文中可定位。拒答单独计数；通过数从逐条结果汇总。
- **改动：**14 条查询中给 13 条有答案案例标注文档版本；每题 64 次回答调用取单次平均耗时；CLI 按分母输出。新增聚焦单测、可追踪快照 `eval/baseline/reference.json`，并更新 README 的复现命令、指标定义和实测结果。
- **影响：**演示语料的实测报告为 14/14，通过数和逐条结果一致；出处存在与来源可核验分开显示。来源核验仅是来源/逐字定位检查，不保证语义事实正确。耗时随设备变化。
- **未完成：**版本生效范围、真实子块检索、多类型文档和保留评测集仍按 `Plan.md` 后续独立任务处理。
- **合并结果：**测试通过后，`fix/evaluation-metrics` 无冲突合回 `work/ragbot`；未合入 `main`。
