# 社区活动场地收费标准说明

## 收费原则
社区公共活动场地对非经营性公益活动免收场租费用。经营性活动按商业场地标准收费。

## 中央广场收费
中央广场舞台区域对经营性活动按每日三千元收取场租。非经营性活动免收场租，但须按补充通知缴纳场地保证金。

## 退费规则
活动取消或改期的，场租费用在活动原定日期前五个工作日提出申请的可全额退还；逾期提出的退还百分之五十。
