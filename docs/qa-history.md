# 常见问题解答汇编（2025年度）

## 关于申请材料
问：2025年申请艺术节需要哪些材料？答：按当年申请指南提交活动方案、安全预案及场地使用说明三项材料。本答复适用于二〇二五年度，二〇二六年起以修订版指南为准。

## 关于审批时限
问：初审需要多久？答：二〇二五年度按十个工作日执行。

## 关于保险
问：是否需要为活动购买保险？答：二〇二五年度无强制保险要求。相关要求以最新指南为准。
