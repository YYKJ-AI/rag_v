# 蓝桥手作营报名与参加指南

## 报名资格
蓝桥手作营面向年满十二周岁的社区居民。未满十八周岁的参加者须由监护人在报名表上签字；年满十八周岁的参加者自行签字即可。年龄按活动首日计算，窗口只核对出生日期，不要求提交额外的年龄证明。
每位申请人只能选择一个主题场次。木工场次和纸艺场次均开放给初学者；曾参加过往期活动的人可以再次报名，但同一季度最多录取一次。这里的录取次数限制与年龄条件是两个独立条件。
轮椅使用者可选择一层无障碍教室，报名时应勾选场地协助需求。场地协助只改变教室安排，不改变报名资格和录取顺序；工作人员不得把协助需求当作拒绝报名的理由。

## 报名步骤与材料
第一步在社区服务平台填写电子报名表，选择主题和场次，并确认联系人电话。平台提交成功只表示收到申请，不等于已录取；申请人可在提交后两日内修改联系人电话。
第二步上传本人身份证件照片；未满十八周岁者另须上传监护人签字页。电子报名表由平台保存，不要求再次打印；窗口现场核验时须出示身份证件原件。
第三步在收到初审通过通知后，到蓝桥社区文化服务窗口核验原件。窗口在核验完成后发放纸质入场卡；未收到初审通过通知的人不能仅凭平台回执领取入场卡。
资料不清晰时，平台会标记“待补正”并一次列出缺项。申请人应在三个工作日内补齐；逾期未补齐的申请留在待处理状态，不自动转为录取，也不自动扣除下一季度名额。

## 场次确认与退出
初审按完整材料提交时间排序，通常在五个工作日内给出结果。报名人数超过教室座位数时，系统只确认排序靠前的申请，其余进入候补；候补序号不是最终录取承诺。
申请人若不能参加，应在活动开始前两个自然日通过平台取消。活动当天缺席不等于已取消，工作人员会记录实际到场情况；退出规则与费用退款规则分别见本指南和预算说明。
场次变更须先取消原场次，再提交新场次申请。工作人员不得直接把原场次的候补序号搬到新场次；新场次按照新的完整材料提交时间重新排序。

## 信息与提醒
服务平台只向申请人显示自己的报名状态和补正清单。工作人员在纸质入场卡上写入场次、日期和座位号，不写身份证号、电话或监护人联系方式。
活动前一日会发送时间提醒。提醒短信不是录取证明；当短信内容与平台审核结果不一致时，以平台当前审核状态为准，并由窗口核实。
